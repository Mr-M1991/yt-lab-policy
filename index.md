# Privacy Policy — yt_lab uploader

_Last updated: 2026-10-14_

**What this application is.** yt_lab is a private, single-user tool that produces short explainer videos
and uploads them to YouTube channels owned by the application's operator (The Daily Pitch, Oddly True, Fit Facts).
It is not offered to the public and has no users other than its operator.

**Data accessed.** Through the YouTube Data API the application uses the scopes `youtube.upload` (to upload videos
to the operator's own channels), `youtube.force-ssl` (to change the privacy status of those videos) and `youtube.readonly` (to read the operator's
own channel id and, later, the statistics of the operator's own videos). It does not access any other Google user
data, comments, subscribers or viewer information.

**Storage.** OAuth tokens are stored only on the operator's own computer in a local folder and are never
transmitted anywhere except to Google's APIs. No data about viewers is collected. Video statistics, when read,
are stored locally for the operator's own reporting.

**Sharing.** No data is shared with third parties. No advertising, no analytics services.

**Deletion.** The operator can revoke the application's access at any time at
https://myaccount.google.com/permissions; local tokens can be deleted by removing the local `secrets/` folder.

to the Google API Services User Data Policy, including the Limited Use requirements.
